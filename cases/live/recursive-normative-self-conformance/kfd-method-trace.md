# KFD method trace

1. KFD-1 fixes the normative and package coordinates.
2. KFD-2 turns the Candidate and replay claims into assessable statements with
   gaps and counterevidence.
3. KFD-4 declares the successor-steward perspective; no historical actor's
   perspective is synthesized.
4. KFD-5 records genesis, alternatives, minimum closure, deletion, fuse,
   falsifiers, dogfood, and an explicit no-new-Primitive outcome option.
5. KFD-11 keeps the generated claim, structural assessment, independent
   review, disposition, and repository admission separate.
6. The Self-Conformance Profile verifies exact transition structure from its
   unchanged bootstrap anchor and fixed package root.

Historical statements are typed as `historical-fact`,
`retrospective-reconstruction`, or `counterfactual-replay`. A later Profile
cannot retroactively turn earlier governance into a conforming Profile run.

The method terminates only with an authority-separated disposition. A valid
structural report remains necessary but insufficient.
