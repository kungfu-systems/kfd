# Ontology split

| Alternative | Smallest responsibility | What remains independently addressable |
| --- | --- | --- |
| New KFD procedure | Recursive self-application as its own normative object | identity, lifecycle, review and disposition |
| KFD-1 + KFD-2 + KFD-5 + KFD-11 closure | Composition of existing responsibilities | exact cuts, trust claim, genesis/qualification, decision/admission |
| Self-Conformance Profile only | Repository-native implementation contract | package root, verifier, receipts, transition chain |
| Governance prose | Maintainer convention | no machine closure; repeated reconstruction remains |
| No action | Existing rules remain distributed | no new surface and no explicit composition |

The Profile is an implementation contract, while numbered KFDs are normative
decisions. That distinction prevents the Profile from silently becoming its
own semantic authority. The central qualification test is whether the proposed
Candidate adds a new responsibility beyond the existing normative closure, not
whether the Profile is useful.
