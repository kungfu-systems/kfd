# KFD Agent Hub C++ starter

This C++17, dependency-free starter demonstrates only the `jsonl-stdio/v1` envelope. `node smoke.mjs` compiles it with the available C++ compiler and executes the fixtures. For a project build, use CMake.

Replace the fail-closed evaluator and fixture-scoped JSON reader with your production JSON and Hub implementation, then run Hub 20 against `./build/kfd-agent-hub-cpp-starter`.

The smoke does not run Hub 20 and is neither qualification nor certification.
