# KFD Agent Hub Python starter

This standard-library-only starter demonstrates only the `jsonl-stdio/v1` envelopes. Run `python3 smoke.py`, then replace `evaluate()` with product-owned Hub semantics before running `kfd test agent-hub --adapter ./adapter.py --output ./agent-hub-report.json`.

The smoke does not run Hub 20 and is neither qualification nor certification. Keep stdout as JSONL and stderr empty during conformance execution.
